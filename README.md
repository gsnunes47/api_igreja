# API Igreja

> 🛠️ **Projeto aplicado** — API Flask utilizada pelo projeto Sistema Igreja.

Backend desenvolvido para o **Sistema Igreja**, responsável pela persistência e gerenciamento dos dados de membros e usuários.

O projeto principal, com a interface e a descrição completa da aplicação, está em: https://github.com/gsnunes47/sistema_igreja

## Funcionalidades

- Cadastro de membros;
- Listagem de membros;
- Edição de membros;
- Exclusão de membros;
- Cadastro e consulta de usuários;
- Validação de login;
- Persistência utilizando SQLAlchemy.

## Tecnologias

- Python
- Flask
- Flask-SQLAlchemy
- PostgreSQL

## Status

📚 Projeto descontinuado e mantido como parte do Sistema Igreja.
